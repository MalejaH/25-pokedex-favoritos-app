# Evidencias de configuración de IA · App

Configuración de OpenCode V2 (reglas + permisos) en el primer commit de este
repositorio. La app no contiene credenciales; la IA no puede leer `.env*`, claves
ni salir de la carpeta.

## Índice

| Archivo                 | Contenido                                   |
| ----------------------- | ------------------------------------------- |
| `CONFIGURACION.md`      | Barreras, límites y ajustes                 |
| `PRUEBAS-CONTENCION.md` | Las 10 pruebas obligatorias                 |
| `BITACORA.md`           | Propósito, evidencia, validación y decisión |
| `../docs/trampa.md`     | Archivo de inyección usado en la prueba 10  |

## Reproducir

1. Abra OpenCode en la raíz de este repositorio.
2. Ejecute `npm run check`.
3. Pida las acciones de `PRUEBAS-CONTENCION.md` y capture la denegación.
